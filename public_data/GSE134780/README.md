# Public GSE134780 input cache

This directory caches public mouse RNA-seq count and GEO metadata inputs from
GSE134780. It contains no hackathon case material. Data provenance: Sieben et al.,
JCI 2020, DOI 10.1172/JCI126863, GEO GSE134780. Public NCBI GEO access is used for
reanalysis with attribution. Upstream files are not redistributed in Git.

Purpose: an independent BubR1 allele/tissue-context sensitivity, under
`analysis/external/GSE134780/PROTOCOL.md`. Computational provenance was checked
on 2026-09-09. Keep downloaded files
ignored and retain checksums and source URLs in the analysis release.
