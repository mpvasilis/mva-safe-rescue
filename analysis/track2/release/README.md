# Track 2 public release snapshot

This directory is a small, reviewable snapshot of the public aggregate outputs from the reproducible pipeline in `analysis/track2`. It lets reviewers inspect the prespecified result branch without downloading the pinned public inputs or rebuilding Bioconductor packages.

The snapshot contains the primary candidate table, configured and evaluable module results, leave-one-batch influence summaries and direction-driver diagnostics, normalized-direction sensitivity, sanity checks, QC summaries and PCA coordinates, figures, relative-path source manifests/checksums, the orthology-policy sensitivity summary, `package_versions.tsv`, and the R reporting-process session information. The package table is the explicit provenance record for every declared or directly used analysis package, including apeglm and roastgsa even when they are not loaded by the final reporting process. The snapshot deliberately omits complete differential-expression tables, exploratory full gene tables, human signatures, and mapping audits.

The authoritative branch is null module support: 13 modules were configured, 12 were evaluable in the primary include-IEA analysis, and zero reached BH q <= 0.10. The transcriptomics therefore does not validate or prefer a specific rescue candidate; named candidates remain prospective preclinical benchmarks only. Leave-one-batch direction reversals are descriptive influence evidence, not statistically supported enrichment. The seven-module nomination subset is transparently labeled as a post-primary implementation amendment fixed before module-level leave-one-batch sensitivity, not as part of the original 13-module analysis lock. The 13-module registry was prespecified and analysis-locked before the authoritative run, but it has no immutable external preregistration timestamp. Historical output filenames and JSON keys containing `preregistered` are retained only for compatibility and do not assert external preregistration. The batch-6 apeglm warnings are retained in the gene-level summary, which also reports unshrunk DESeq2 effect diagnostics. All 179 full candidates retain unshrunk-effect direction in every omission; this remains a non-inferential influence diagnostic, not a batch-stable significance claim.

GSE301548 is exploratory/adversarial only: its controls were dissected at 5 days AEL and its trisomies at 8 days AEL, so chronological age is perfectly confounded with genotype. Its `CDXX_vs_CDXY` and `T2L_vs_C2L` results estimate combined age+genotype contrasts, cannot identify genotype effects, and are excluded from primary inference and candidate ranking.

Two null-branch sensitivity findings are intentionally prominent. `proteostasis_stress` changes from full module q=0.547625 to q=0.0013 only when batch 5 is omitted, a fragile n=4 result that cannot override the full null. Excluding IEA flips `folding_proteasome` from NES=-1.178407/q=0.69966 to NES=1.425172/q=0.43238; both policies remain null. In module tables, decisions use only `module_qvalue` (BH over all 13 configured modules); `roastgsa_adj_pvalue_evaluable_only` is retained for transparency and is not the decision column.

The orthology sensitivity maps 6,808 human genes under the primary DIOPT>=5 max-tie policy and 11,861 under the DIOPT>=3 weighted policy. Across the 6,808 shared scores, Spearman correlation is 0.932 and sign concordance is 94.6%, but only 17 genes overlap between the two top-100 absolute-score lists. Global direction is stable, while top human-gene prioritization is mapping-dependent; no top-gene nominee is robust without dual-policy review.

`release_inventory.tsv` records a SHA-256 digest and byte count for every snapshot artifact, including this README. `release_inventory.sha256` records the inventory's own digest. The snapshot is refreshed from an explicit whitelist by the `release_files` target after `result_files`; its whitelist is implemented in `R/release.R`.
